# 产前运动互动：自动讲解版

主场景：Assets/产前运动/场景/产前运动互动.unity。

## 使用

点击 Play，护士逐字显示原始开场白，自动推进安全提示和各项运动的讲解；每项结束必须点击“确认完成”，不会自动跨过运动。固定介绍不需要 API；当前仍是文字讲解，没有护士语音。每页文字完整显示后固定停留5秒，再自动进入下一页或下一段。参数位于“护士讲解管理器”的“护士顺序讲解”组件。

对白下方输入框常驻，中文输入或未发送草稿会暂缓讲解。点击发送或按回车向护士提问，收到回复后自动分页阅读并回到原讲解段落和页码。失败保留问题；清空草稿并移开焦点后可以恢复。点击“暂停讲解”可暂停；“继续讲解”会暂停视频、取消未完成问答并恢复固定内容；未发送文字仍保留，会继续阻止自动推进。

视频准备、播放或暂停观看时，固定讲解暂缓；播放结束后延迟3秒恢复。观看中可以随时点击“继续讲解”提前恢复。打开声音设置也会暂缓文字；关闭后恢复。多个暂停原因同时存在时，需要全部解除。

## 视频与设置

独立视频屏已向玩家移近至前方约2.1米，仍固定在3D场景中、正面摆放。底部提供上一个、播放、暂停、重播、下一个按钮、进度条和当前时间/总时长。拖动进度条后保持拖动前的播放或暂停状态。切换视频停止旧片，不自动播放下一片。竖屏视频保留比例。

视野左上角的“设置”打开声音面板，调节视频音量0–100%，0%静音；首次默认50%，关闭设置后保存，下次启动读取。仅控制视频专属AudioSource；无音轨片源正常出画但无声。护士不添加语音。

五项视频来自 Assets/Vedio，已按用户文件名绑定在 Assets/产前运动/配置/护士对白配置.asset 的 exercises 列表。替换对应 videoClip 即可。文件及GUID保留。用户要求按名称绑定，不将绑定结果作为内容或商用授权审核。

## API

选择护士对白配置，在Inspector“对话 API 配置”的API密钥字段中填写DeepSeek密钥，Endpoint与Model填写对应接口和模型。不需要环境变量。密钥会保存在配置资源中，分享项目时清空真实密钥。

接口超时30秒，失败保留输入，最近十轮成功问答仅在运行内存中保存；停止运行或返回讲解会取消请求。2026-09-14已有一次真实API问答通过；后续UI改造的验证结果另见交付记录。

## 2026-09-19 分阶段学习更新

保持3D第一视角、五个原视频、常驻输入和音量设置。每项先显示“准备开始”，对白逐字出现（默认每秒18字，可在对话面板组件调整），本页文字完整后才计算阅读停留时间。

每项末尾停留等待“确认完成”。只有玩家确认才能进入30秒休息，然后进入下一运动；最后一项确认后结束。设置、未发送草稿、提问、手动暂停和视频观看均会暂缓自动推进。重看本项重新开始当前引导，但已确认项目不重复累计学习安心值。

设置入口移至独立世界空间工具栏，固定在视野左上角。视频维持手动播放，未新增VR输入、语音或麦克风。

系统反馈在视频画面区域展示，播放视频时暂时隐藏：凯格尔电梯楼层亮灯、3秒收缩/3秒放松8组，以及5秒/5秒4组，显示引导星星与进度；疲劳时可跳过当前节拍轮次。踝泵、上肢、骨盆倾斜、呼吸呈现动作意象；其循环只是可调的演示节奏，不新增规定训练次数。每个项目由玩家首次确认后计入1点“学习安心值”，不是实际动作检测、肌力评分或医疗效果评估。暂未接入手柄震动、护士动画或麦克风屏气检测。
